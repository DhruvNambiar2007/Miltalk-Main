The learning loop

Cause a mistake. Investigate it. Improve it.

Students run a short experiment, watch the results and change the examples themselves.

1

Train

Give the kit examples for two categories.

2

Test

Try an example it has not seen before.

3

Investigate

Notice the wrong result and ask which examples led to it.

4

Improve

Add or change examples, then test again.

A score can be high and still be wrong. Students learn to check each prediction against what actually happened.

Choose the input

Two kits. One shared learning loop.

Miltalk Vision Kit

Train with images

Use its camera to collect visual examples: colour, shape, angle and light all become part of the investigation.

Miltalk Audio Kit

Train with sound

Use its microphone to compare sounds and explore how volume, rhythm and surroundings affect a result.

What students learn

Data shapesa model’s answers

Examples that are too narrow can produce a result that does not hold up in a new situation.

Test an ideawith evidence

Students make a prediction, change one thing and see whether the evidence supports it.

Questionconfidence scores

A model can give a high confidence score for an incorrect prediction. Students test how its scores hold up on new examples.
